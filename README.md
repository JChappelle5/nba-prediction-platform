\# NBA Prediction Platform



A web application where users can predict NBA game winners, earn points for accuracy, and compete on a leaderboard.



\## Features (Planned)

\- User authentication and profiles

\- Predict winners of upcoming NBA games

\- Points-based scoring system

\- System-generated predictions with confidence scores

\- User leaderboard



\## Tech Stack

\- \*\*Frontend:\*\* React, Tailwind CSS

\- \*\*Backend:\*\* Node.js, Express

\- \*\*Database:\*\* PostgreSQL

\- \*\*API:\*\* BallDontLie NBA API



\## Database Schema

See `/database/schema.sql` for the complete database design including:

\- Users and authentication

\- NBA teams and games

\- User predictions with scoring

\- System predictions with confidence ratings
